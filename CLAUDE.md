# Reglas del proyecto

## Atribución a Claude — prohibida en todo lugar visible del repo o de Jira

Este proyecto es una tesis de grado (HEXtructure S.A.S., UDLA) y **no debe aparecer ninguna
mención a Claude, Claude Code o Anthropic en ningún lugar visible del repositorio ni de Jira.**
Esto incluye, sin excepción:

- Mensajes de commit (nada de `Co-Authored-By: Claude...`, `Claude-Session:`, ni similares).
- Descripciones de Pull Request.
- Comentarios normales en PRs o issues.
- Reviews de PR (cuerpo del review y comentarios en línea).
- Comentarios en Jira.

Antes de escribir cualquier texto en alguno de estos lugares, revisar que no incluya nada de
lo anterior. Esta regla no admite excepciones salvo que el usuario la cambie explícitamente
en esta conversación.

**Precaución conocida:** la herramienta de reviews de PR de GitHub (`pull_request_review_write`)
ha inyectado el footer "Generated by Claude Code" de forma automática en el pasado, sin que el
texto enviado lo incluyera. Por eso, para dar feedback de código en un PR, usar un comentario
normal (`add_issue_comment` / equivalente) en vez de un review formal — un comentario normal sí
se puede editar después por API si algo sale mal; un review formal no tiene forma de editarse
una vez enviado. Después de publicar cualquier review o comentario, releerlo desde GitHub para
confirmar que salió limpio.
