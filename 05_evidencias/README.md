# 05 — Evidencias

Evidencia del proceso de ingeniería, organizada por sprint.

Responde a la sección 7.2 del formato capstone, que exige demostrar que la
metodología se **ejecutó**, no solo que se declaró.

## Organización

```
05_evidencias/
├── sprint-01/
│   ├── backlog.png              Product Backlog priorizado
│   ├── tablero.png              Tablero al cierre del sprint
│   ├── burndown.png             Gráfico de burndown
│   ├── velocidad.png            Gráfico de velocidad
│   └── retrospectiva.md         Acuerdos de la retrospectiva
├── sprint-02/
└── capturas/                    Capturas del sistema en funcionamiento
```

## Qué archivar al cierre de cada sprint

| Evidencia | Dónde obtenerla |
|---|---|
| Product Backlog priorizado | Jira → Backlog |
| Historias con criterios de aceptación | Jira → detalle de cada historia |
| Tablero del sprint | Jira → Board |
| Gráfico de burndown | Jira → Reports |
| Gráfico de velocidad | Jira → Reports |
| Informe del sprint | Jira → Sprint Report |
| Pull requests revisados | GitHub → Pull requests |
| Ejecución de pruebas en CI | GitHub → Actions |

## Retrospectivas

Cada carpeta de sprint incluye `retrospectiva.md` con lo que funcionó, lo
que no, y los acuerdos adoptados. Es la evidencia más difícil de improvisar
al final y la que mejor demuestra que el proceso fue real.
